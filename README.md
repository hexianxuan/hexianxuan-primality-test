# hexianxuan-primality-test
This program is developed based on He Xianxuan's Primitive Root Theorem and He Xianxuan's Primality Theorem.
Formal theorem archive DOI: https://doi.org/10.5281/zenodo.21333058

https://orcid.org/0009-0005-1999-250X

When the smallest primitive root exceeds 10 million, the conventional exhaustive search method for primitive roots suffers from computational breakdown. The Hexianxuan primality test, developed based on the Hexianxuan Primitive Root Theorem and Hexianxuan Primality Theorem, enables rapid computation of primitive roots for arbitrarily large integers.

当最小原根大于1000万时,传统搜索原根逐一检索,陷于崩溃,何先玄素性检测基于何先玄原根定理和何先玄素性定理研发,可快速找到任意大数原根。
