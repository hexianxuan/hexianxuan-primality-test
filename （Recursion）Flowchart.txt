Input: Integer n to test, n ≥ 2

Step 1: Basic Pre-Screen
┌─────────────────────────────────────────────────────────────────────────────┐
│  n < 2 ?                                                                    │
│    ├─→ 是 → 输出无效值，结束｜Yes → Output invalid, Terminate                    │
│    └─→ 否 → 继续｜No → Proceed                                              │
│                                                                             │
│  n == 2 ?                                                                   │
│    ├─→ 是 → 输出【素数】，结束｜Yes → Output Prime, Terminate                │
│    └─→ 否 → 继续｜No → Proceed                                              │
│                                                                             │
│  n % 2 == 0 ?                                                               │
│    ├─→ 是 → 输出【合数】（偶数>2），结束｜Yes → Output Composite (Even>2), Terminate

Step 2: Small Prime Trial Division (up to 97)
┌─────────────────────────────────────────────────────────────────────────────┐

│           53, 59, 61, 67, 71, 73, 79, 83, 89, 97}:                         │
│  For each p in the set above:                                               │
│                                                                             │
│    n % p == 0 ?                                                             │
│      ├─→ 是 → 输出【合数】（因子p），结束｜Yes → Output Composite (Factor p), Terminate
│      └─→ 否 → 继续下一个p｜No → Next prime p                                │
│                                                                             │
│  所有小质数试除完毕 → 进入步骤3｜All small primes tested → Go to Step 3      │
└─────────────────────────────────────────────────────────────────────────────┘

步骤3: 费马小定理检验
Step 3: Fermat's Little Theorem Test
┌─────────────────────────────────────────────────────────────────────────────┐
│  对 a ∈ {2, 3, 5, 7, 11}:｜For each base a ∈ {2, 3, 5, 7, 11}:             │
│                                                                             │
│    gcd(a, n) > 1 ?                                                          │
│      ├─→ 是 → 输出【合数】（找到因子gcd(a,n)），结束｜Yes → Composite with factor gcd(a,n), Terminate
│      └─→ 否 → 继续｜No → Proceed                                             │
│                                                                             │
│    a^(n-1) mod n == 1 ?                                                     │
│      ├─→ 否 → 输出【合数】（费马检验失败），结束｜No → Composite (Fermat test failed), Terminate
│      └─→ 是 → 继续下一个a｜Yes → Next base a                                │
│                                                                             │
│  所有基通过 → 进入步骤4（何先玄核心）｜All bases passed → Core Step 4         │
└─────────────────────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤4: 何先玄核心 - 阶结构检验（第一层）
Step4 Core: Multiplicative Order Test (Layer 1)
┌─────────────────────────────────────────────────────────────────────────────┐
│  选取初始元素 a（通常 a = 2）｜Pick initial base a=2                        │
│                                                                             │
│  计算 k = ord_n(a)（a模n的阶）｜Compute k = ordₙ(a), multiplicative order of a mod n
│                                                                             │
│  k 是否整除 (n-1) ?｜Does k divide n−1?                                     │
│    ├─→ 否 → 输出【合数】（阶不整除n-1），结束｜No → Composite (order ∤ n−1), Terminate
│    └─→ 是 → 继续｜Yes → Proceed                                             │
│                                                                             │
│  k == n-1 ?｜Is k equal to n−1?                                             │
│    ├─→ 是 → 输出【素数】（a是原根），结束｜Yes → Prime (a is primitive root), Terminate
│    └─→ 否 → 进入步骤5（同余方程递推）｜No → Recurrence Step 5               │
└─────────────────────────────────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

步骤5: 何先玄核心 - 同余方程递推
Step5 Core: Congruence Recurrence Iteration
┌─────────────────────────────────────────────────────────────────────────────┐
│  计算 m = (n-1) / k｜Compute m = (n−1) / k                                  │
│                                                                             │
│  解同余方程: x^m ≡ a (mod n)｜Solve congruence xᵐ ≡ a (mod n)               │
│                                                                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│                                                                             │
│  方程是否有解 ?｜Does solution exist?                                        │
│    ├─→ 否 → 输出【合数】（同余方程无解），结束 ★关键筛出机制｜No → Composite (no solution), Key screening rule
│    └─→ 是 → 继续｜Yes → Proceed                                             │
│                                                                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│                                                                             │
│  检查解集S = {x_1, x_2, ..., x_r}｜Inspect solution set S = {x₁,x₂…xᵣ}     │
│                                                                             │
│  解集中是否存在原根 ? （即存在x使得 ord_n(x) = n-1）｜Any primitive root in S (∃x, ordₙ(x)=n−1)?
│    ├─→ 是 → 输出【素数】（定理I保证），结束｜Yes → Prime (Theorem I guarantee), Terminate
│    └─→ 否 → 继续｜No → Proceed                                              │
│                                                                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│                                                                             │
│  对所有解 x ∈ S，计算 k_1 = ord_n(x)｜Compute k₁=ordₙ(x) for every x ∈ S    │
│                                                                             │
│  所有解是否满足 gcd(k_1, m) = 1 ?｜For all x, gcd(k₁,m)=1?                  │
│  （即所有解的阶不提升: k_1 = k，无法递推）｜Meaning order cannot be elevated, no valid recurrence
│                                                                             │
│    ├─→ 是 → 输出【合数】（同余方程所有解的阶不提升），结束｜Yes → Composite (no order elevation), Terminate
│    └─→ 否 → 继续（存在可递推解）｜No → Valid iterative solution exists      │
│                                                                             │
│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│                                                                             │
│  选取满足 gcd(k_1, m) > 1 的解 x 作为新的 a｜Select x with gcd(k₁,m)>1 as new base a
│                                                                             │
│  验证核心等式: k_1 == k * gcd(k_1, m) ?｜Verify core identity k₁ = k·gcd(k₁,m)
│    ├─→ 否 → 输出【合数】（核心等式不成立），结束｜No → Composite (core identity invalid), Terminate
│    └─→ 是 → 继续｜Yes → Proceed                                             │
│                                                                             │
│  计算 m_1 = (n-1) / k_1｜Compute m₁ = (n−1)/k₁                               │
│                                                                             │
│  m_1 < m ? （严格递减）｜Is m₁ strictly smaller than m?                      │
│    ├─→ 否 → 输出【合数】（递推不递减），结束｜No → Composite (m not decreasing), Terminate
│    └─→ 是 → 令 a = x, k = k_1, m = m_1，返回步骤5继续递推｜Yes → Update a=x, k=k₁, m=m₁, loop back Step5
│                                                                             │
│  （递推深度限制: 若超过最大步数仍未找到原根，输出【合数】）｜Max iteration depth limit: output composite if primitive root not found after max steps
└─────────────────────────────────────────────────────────────────────────────┘

Summary of Composite Screening Rules
┌─────────────┬──────────────────────────────────────────────────────────────┐
│ 筛出层级    │ 机制｜Screen Layer │ Screening Mechanism                          │
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤1       │ n < 2, n = 2（特例）, 偶数 > 2｜n<2, n=2 special case, even n>2 │

│ 步骤3       │ 费马小定理失败: a^(n-1) ≢ 1 (mod n)｜Fermat test failure aⁿ⁻¹≢1 mod n
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤4       │ 阶不整除n-1: ord_n(a) ∤ (n-1)｜ordₙ(a) does not divide n−1      │
│             │ （素数要求所有元素阶整除p-1）｜Prime requires all orders divide p−1
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤5-①    │ 同余方程无解: x^m ≡ a (mod n) 无解｜No solution for xᵐ≡a mod n   │
│             │ （如Carmichael数 n=561, m=14, 模3下无解）｜Example: Carmichael number 561, no solution mod3
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤5-②    │ 解集中无原根且所有解阶不提升｜No primitive root & no order elevation for all solutions
│             │ （所有解满足gcd(k_1,m)=1，无法递推）｜All x satisfy gcd(k₁,m)=1, iteration blocked
│             │ （如 n=15, a=4, x=4, k_1=k=2, gcd(2,7)=1）｜Example n=15,a=4
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤5-③    │ 核心等式不成立: k_1 ≠ k * gcd(k_1, m)｜Core multiplicative identity fails
│             │ （方程有解时理论上恒成立，但合数上可能前提不满足）｜Identity holds for primes only
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤5-④    │ 递推不递减: m_1 ≥ m｜m₁ fails strict decrease m₁ ≥ m          │
│             │ （素数上必有m_1 < m的可递推解或原根）｜Primes guarantee strictly decreasing m
├─────────────┼──────────────────────────────────────────────────────────────┤
│ 步骤5-⑤    │ 递推深度超限: 超过最大步数仍未找到原根｜Max iteration depth reached without primitive root
│             │ （素数上递推有限步必终止于原根）｜Primes converge to primitive root in finite steps
└─────────────┴──────────────────────────────────────────────────────────────┘

【素数 vs 合数的关键区别】
Key Distinction: Prime vs Composite n
┌─────────────────┬────────────────────────────────────────────────────────────────────┬────────────────────────────────────────────────────────────────────┐
│ 判定性质        │ 若 n 为素数｜If n is prime (𝕫ₙ^* cyclic group)                   │ 若 n 为奇合数｜If n is odd composite (𝕫ₙ^* non-cyclic)
├─────────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 群结构          │ 模n乘法群是阶n−1循环群，必存在原根｜Multiplicative group cyclic of order n−1, primitive root exists
│ 𝕫ₙ^* Structure │                                                                 │ Group not cyclic, φ(n)<n−1, no primitive roots
├─────────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 元素阶约束      │ ∀a∈𝕫ₙ^*, ordₙ(a) | n−1｜All orders divide n−1                   │ ∃a, ordₙ(a) ∤ n−1, fails Step4
├─────────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 同余方程xᵐ≡a   │ 循环群内必有解，不会触发步骤5①筛除｜Congruence always solvable    │ Frequently unsolvable, filtered at Step5-①
├─────────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 递推行为        │ m严格递减，有限步得到原根终止｜m strictly decreasing, converge to primitive root in finite steps
│ Iteration Behavior │                                                                 │ Iteration blocked at any screening branch early exit
├─────────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────────────────────────────────────────────────┤
│ 终止结果        │ 必然输出素数｜Final output: Prime                                  │ Must trigger composite exit rule early
└─────────────────┴────────────────────────────────────────────────────────────────────┴────────────────────────────────────────────────────────────────────┘
